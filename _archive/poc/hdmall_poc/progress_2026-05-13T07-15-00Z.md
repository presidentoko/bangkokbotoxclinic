## Blockers / Bugs fixed

- Regex `[^<\n]+` failed on `\n4.0` (rating on newline after img). Fixed with `\s*([0-9]+\.?[0-9]*)`.
- Cache key collision: Thai slugs all became `____` after regex strip. Fixed with MD5 hash.
- Pagination: each sitemap/brands page shows 100 brands max. Fixed with `?page=N` loop.
- Dedup: same (category, slug) appearing multiple pages. Fixed with `seen_keys: set[tuple]`.
