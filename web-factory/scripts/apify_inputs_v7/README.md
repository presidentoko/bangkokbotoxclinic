## 실행 방법

1. 액터 열고 Input 탭 → **JSON** 모드
2. 파일 내용 붙여넣고 Start
3. Dataset → Export → **JSON**
4. `data/apify_raw/2026-10-04/` 에 넣기 (파일명 그대로) — 자동 리빌드가 10분 안에 집어간다
