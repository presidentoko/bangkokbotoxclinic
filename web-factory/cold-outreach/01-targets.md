# 콜드 이메일 타겟 리스트 — 한국 OEM 바이어 + 무역 에이전시

목적: thaisupplyhub.com 에 RFQ 보낼 잠재 한국 바이어를 콜드 이메일로 발굴.

## 타겟 유형 (Tier 1 = 가장 높은 ROI)

### Tier 1 — 한국 OEM 에이전시 / 소싱 회사

\"중국 OEM 단가 오르고 베트남도 한계라 태국 알아본다\" 사장님들. RFQ 1건 = $500-수천 거래 가능.

**찾는 법:**

1. **이엔에프 (ENF)** — 한국 화장품/식품 OEM 에이전시 (https://enfcorp.com)
2. **한국무역상사 (KITA)** — 협회 통해 회원사 리스트 (1만+사)
3. **알리바바 한국 베리파이드 셀러** — 알리바바 가입 한국 바이어 (지역 검색 \"Korea\")
4. **GS Shop / CJ Mall 소싱팀** — 홈쇼핑 PB 발주
5. **무신사 / 29cm / 마켓컬리** — D2C 자체 브랜드 PB
6. **올리브영 / 랄라블라** PB 팀

**검색 키워드 (구글):**

- \"OEM 에이전시\" site:cafe.naver.com
- \"태국 OEM\" site:blog.naver.com
- \"sourcing manager\" site:linkedin.com/in/ \"Korea\"
- \"태국 화장품 OEM\" filetype:pdf

### Tier 2 — 한국 SME 브랜드 (D2C)

K-Beauty, 식품, 가전, 의류 등 자체 브랜드 운영하는 중소 사장님. 단가 부담으로 OEM 옮기는 움직임.

**찾는 법:**

1. **무신사 입점 브랜드** (https://www.musinsa.com) — 신생 패션 D2C
2. **29cm / W컨셉** — 라이프스타일 D2C
3. **올리브영 입점 브랜드** — 화장품 D2C
4. **쿠팡 PB / 자체 입점 브랜드** — 식품/생활용품
5. **네이버 스마트스토어 매출 상위** — 카테고리별

**스크래핑 가능:**

- 무신사: 입점 브랜드 페이지 → 브랜드명 + 사업자 정보 (사업자번호 노출시)
- 사업자번호 → 국세청 사업자등록증 조회 → 본사 주소 → 콜드 메일 발송지

### Tier 3 — KOTRA, 무역협회, 산업부 산하

정부 / 협회. 직접 거래 아니지만 \"무료 directory 광고 효과\" 노림.

1. **KOTRA 방콕 무역관** — 한국 기업 태국 진출 지원. 우리 사이트 무료 소개 가능.
2. **한국무역협회 (KITA)** — \"태국 시장 정보\" 컨텐츠 제공
3. **중소벤처기업진흥공단** — 해외 진출 컨설팅
4. **한국화장품산업연구원** — 화장품 사장님 다수 회원
5. **한국식품연구원** — 식품 OEM 발주 정보

**메일 방향:** 거래 제안 아닌 \"무료 리소스 제공\" 톤. 그들 채널에 우리 사이트 노출되면 한국 사장님 트래픽 폭증.

### Tier 4 — 한국 무역 컨설팅 / 변호사

부수 채널. 이 사람들이 \"태국 OEM 알아보세요\" 추천하면 우리한테 트래픽.

1. **법무법인 광장 / 김앤장 / 율촌** 해외투자팀 — 한국 SME 태국 진출 자문
2. **회계법인 KPMG / EY / Deloitte 코리아** 국제거래팀
3. **무역 컨설팅 회사** (이엘티, 다림 등)

## 실전 수집 방법

### 방법 1: LinkedIn Sales Navigator (유료)

- 월 \\₩100,000
- 한국 + \"sourcing manager\" / \"OEM\" / \"buyer\" 필터
- 메일 자동 수집 + 발송 (Linked Helper 또는 Lemlist 같이)

### 방법 2: 무신사 + 사업자번호 크롤링 (무료)

- 무신사 입점 브랜드 → 브랜드 상세 페이지 → 사업자번호 노출 (요건 충족시)
- 국세청 사업자등록증 조회 (https://www.nts.go.kr) — 본사 주소 + 대표자
- 본사 주소로 콜드 우편 또는 \"contact@브랜드도메인\" 메일

### 방법 3: 네이버 카페 (수동)

- 네이버 카페 \"한국 무역 사장님\" / \"한국 사업자\" 등 활성 카페
- 회원 닉네임 + 게시글 흐름 보고 OEM 관심 있는 분 식별
- 쪽지 또는 카페 댓글 컨택 (스팸 X, 정중하게)

### 방법 4: 한국 무역 박람회 참가자 리스트

- KOTRA 주관 \"태국 무역 박람회\" — 참가자 명단 일부 공개
- COEX / 킨텍스 박람회 무료 입장권 받아서 직접 방문 + 명함 교환

## 콜드 이메일 법적 / 윤리적 주의

- 한국 정보통신망법: 광고 메일은 수신자 동의 필요. \"콜드 이메일\"이 명확히 광고면 위반 가능.
- 회피 방법: 첫 메일은 \"광고\" 아닌 \"무료 가치 제공\" (우리 directory 무료 리소스로 소개)
- 불법 X: KOTRA / 무역협회 / 사업자 공개 정보 활용 콜드 메일은 일반적으로 OK
- 두 번째 메일부터: 명시적 unsubscribe 옵션 + 수신거부 명시
