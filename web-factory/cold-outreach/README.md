# 콜드 이메일 캠페인 — 한국 OEM 바이어 발굴

thaisupplyhub.com 의 RFQ funnel에 한국 바이어 트래픽 유입을 위한 콜드 이메일 캠페인 자료.

## 파일 구성

1. [`01-targets.md`](./01-targets.md) — 타겟 리스트 (Tier 1-4 분류) + 수집 방법
2. [`02-templates.md`](./02-templates.md) — 이메일 템플릿 4가지 (A/B 테스트용)
3. [`03-tracking.csv`](./03-tracking.csv) — 발송 / 응답 추적 (Google Sheets 임포트)

## 빠른 시작

### Week 1 — 워밍업

- 타겟 리스트 50명 수집 (Tier 1 + Tier 2 위주)
- 템플릿 A 또는 D로 1일 10-15명씩 발송
- 추적 스프레드시트에 매일 기록

### Week 2-4 — 확장

- 응답 본 거 분석 → 가장 좋은 템플릿 30/70 비율로 추가 발송
- 응답한 사람들 화상 통화 / RFQ 매칭 진행
- 발송 1일 20-30명으로 증가

### Month 2-3 — 자동화

- Lemlist 또는 Apollo.io 도입
- 자동 팔로업 (5일 후 + 12일 후)
- 1일 50-100명 발송

## 성공 지표 (KPI)

| Metric | Target | Stretch |
|---|---|---|
| 응답률 | 5% | 10% |
| 화상 통화 전환 | 30% of 응답 | 50% |
| RFQ 발송 진행 | 10% of 응답 | 25% |
| 거래 성사 | 2-5건/3개월 | 10건 |

## 거래 1건 가치

- RFQ 1건 → 거래 성사 → $5K-50K 거래 (직접 중개 수수료 5-15%)
- 또는 광고/스폰서 슬롯 전환 — 공급사가 우리 검증 배지 구매

3개월 캠페인 예상 ROI: 거래 5건 × $20K 평균 × 10% = **$10,000+ 직접 수익**

## 자동화 발전 단계

- **Phase 1 (지금)**: Gmail 수동 발송. 추적 CSV 수동 갱신.
- **Phase 2 (월 1-2)**: Lemlist 도입. 팔로업 자동.
- **Phase 3 (월 3+)**: Apollo + CRM 연동. 응답 자동 분류 + RFQ 매칭.

## 법적 / 윤리 주의

- 한국 정보통신망법 광고 메일 규제 — 첫 메일은 "광고" 아닌 "가치 제공" 톤
- 명시적 unsubscribe 옵션 유지
- 수신거부 즉시 리스트 제거 + 영구 보관
- KOTRA / 협회 회원 정보 활용은 "공개 정보 + 정상적 비즈니스 컨택" 범위 내
