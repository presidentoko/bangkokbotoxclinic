# 콜드 이메일 템플릿 — 한국 OEM 바이어용

A/B 테스트용 4가지 톤. 본인 상황 맞춰 mix.

## 핵심 원칙

1. **첫 메일은 광고 아님** — 가치 제공 ("무료 리소스 보내드림")
2. **회사 1-2명만 타겟** — 단체 발송 X
3. **개인화** — 받는 사람 회사명 + 그쪽 카테고리 매핑
4. **CTA 1개** — RFQ 폼 또는 사이트 방문
5. **짧게** — 200자 이내 (한국 사장님은 긴 메일 안 읽음)

## 템플릿 A — "무료 리소스 톤" (가장 안전)

**제목:** 태국 OEM 한국 사장님 가이드 — [회사명]에 도움될까 싶어

```
안녕하세요. [회사명] 사장님.

[본인 이름]이라고 합니다. 태국 OEM directory thaisupplyhub.com 운영해요.

태국 등록 사업자 3,305곳 (제조사/공급사) 중 853곳 DBD 검증 (태국 상무부 공식 등록) 데이터를 직접 매칭해서 정리해뒀어요. K-Beauty / 식품 OEM 발주 알아보시는 사장님들 가장 많이 묻는 거 정리한 가이드도 무료로 제공합니다:

- [태국 OEM 처음 알아보는 분 가이드](https://thaisupplyhub.com/ko/blog/thailand-oem-first-guide)
- [알리바바 vs 태국 직접 소싱 비교](https://thaisupplyhub.com/ko/blog/alibaba-vs-thailand-direct)
- [DBD 검증이 뭐고 왜 중요한가](https://thaisupplyhub.com/ko/blog/dbd-verification-explained)

[회사명]의 [제품 카테고리] 발주에 도움 되면 좋겠어요. 혹시 태국 OEM 알아보신 적 있으시면 우리 사이트가 어떻게 더 좋아질 수 있는지 피드백 받을 수 있을까요?

— [이름]
[연락처]
```

**언제 쓸까:** 첫 콜드 메일. 가장 안전. 광고 아니라 \"가치 제공\" 톤이라 응답률 5-15%.

## 템플릿 B — "직접 제안 톤"

**제목:** 태국 OEM 무료 매칭 — [카테고리] 5-10곳 RFQ 받아드림

```
[회사명] 사장님 안녕하세요.

[본인 이름]입니다. thaisupplyhub.com — 태국 OEM directory 운영합니다.

[회사명]이 [제품 카테고리] 한국 시장 운영하시는 거 보고 메일 드려요. 만약 태국 OEM 알아보고 계시거나 단가 비교 한 번 해보고 싶으시면:

1. 본인 spec 한국어로 보내주시면
2. 우리 directory에서 DBD 검증된 5-10곳 공급사한테 RFQ 자동 발송
3. 견적 비교 정리해서 드림

무료입니다. 거래 성사돼도 수수료 X (우리 비즈니스 모델은 다른 데서). 첫 케이스는 가벼운 spec으로 한 번 시도해보시면 좋을 것 같아요.

관심 있으시면 답장 부탁드립니다.

— [이름]
[연락처]
https://thaisupplyhub.com
```

**언제 쓸까:** 명확한 OEM 의향이 있을 것 같은 회사 (무신사 신생 D2C, 올리브영 입점사 등). 응답률 3-8%.

## 템플릿 C — "팔로업 — 1주 후"

A 또는 B 메일 보낸 후 응답 없을 때:

**제목:** Re: 태국 OEM 가이드 (지난주 메일 따라서)

```
[이름] 사장님,

지난주 보낸 메일 못 보셨을 수 있어서 짧게 다시:

태국 OEM 알아보실 때 [관련 가이드 1개 링크]가 도움 될 거예요. 특히 한국 사장님들 자주 빠지는 함정 정리해뒀어요.

혹시 \"태국 OEM 알아볼까 말까\" 고민 단계시면 30분 무료 상담 가능 (전화 또는 카톡). 부담 없이 답장 주세요.

답장 안 주셔도 괜찮습니다. 혹시 메일 받기 싫으시면 [unsubscribe 링크 또는 \"수신거부\" 회신] 부탁드려요.

— [이름]
```

**언제 쓸까:** 첫 메일 5-7일 후. 응답률 2-5% 추가 발생.

## 템플릿 D — "특정 인사이트 톤" (가장 personalized)

상대방 회사 / 산업에 맞춰 깊이 있게 작성. 응답률 가장 높지만 시간 많이 듦.

**제목:** [회사명] 사장님 — [업종] 태국 ODM 트렌드

```
안녕하세요 [이름] 사장님.

[회사명]이 [특정 제품 라인] 운영하시는 거 흥미롭게 봤어요. 특히 [구체적 관찰 — 예: 최근 출시한 ㅇㅇ 라인]이 [업종] 한국 시장에서 잘 받으시는 것 같습니다.

이런 [업종] 카테고리는 사실 태국 OEM 단가 우위가 큰 곳이에요. 우리 directory 데이터로 보면 한국 OEM 대비 25-35% 절감 (같은 spec MOQ 2,000+ 기준).

특히 사장님 회사에 매칭될만한 공급사 3곳:

- [공급사 1] (방콕, 자본금 ฿100M, DBD 검증 강함) — [한 줄 설명]
- [공급사 2] ([도시], 자본금 ฿X, DBD 검증) — [설명]
- [공급사 3] ([도시], 자본금 ฿X, DBD 검증) — [설명]

위 3곳 RFQ 한 번 보내보시면 시장가 파악 + 본인 한국 OEM 단가 비교 가능합니다. 우리가 영문 번역 + 응답 정리까지 무료.

답장 주시면 다음 단계 안내드릴게요.

— [이름]
[연락처]
```

**언제 쓸까:** Tier 1 또는 큰 한 방 노릴 회사. 시간 1건당 30-60분 소요. 응답률 10-25%.

## 응답 받고 나면 — 후속

응답이 오면:

1. **\"흥미 있음\" / 정보 요청** — 화상 통화 또는 카톡 상담 제안. 본인 spec 더 받기.
2. **\"태국 OEM 안 함\"** — 정중하게 감사 + 우리 사이트 즐겨찾기 추천. 6개월 후 재컨택.
3. **\"수신거부\"** — 즉시 리스트 제거. 절대 재발송 X.
4. **\"무료로 RFQ 보내드림\" 수락** — 본인 spec 받고 우리 directory에서 5-10곳 공급사 컨택 + 응답 정리.

## A/B 테스트 권장 분배

처음 100명 발송시:

- 30% 템플릿 A (안전)
- 30% 템플릿 B (직접)
- 40% 템플릿 D (개인화)

응답률 가장 좋은 거 추가 사용.

## 발송 도구 추천

- **Gmail 직접** — 1일 50건 한계. 가장 진정성 있음 (스팸 필터 통과율 ↑).
- **Lemlist / Mailshake** — 자동 personalization + 추적. 월 \\₩50,000-100,000.
- **Apollo.io** — 이메일 검증 + 자동 발송 + LinkedIn 통합. 월 \\₩100,000+.
- **Reply.io** — 한국 사장님 한국어 응답 추적 좋음.

처음엔 Gmail 수동이 가장 안전. 응답 패턴 익숙해진 후 자동화.

## 발송 페이스

- **1일 10-20건** — 안전. 스팸 필터 통과율 99%.
- **1일 30-50건** — Gmail 한계. 자주 보내면 일시 정지.
- **1일 100+ 건** — 전용 도메인 + warm-up 필요.

3개월 캠페인 = 약 1,500-3,000건 발송. 응답률 5% 가정시 75-150건 응답. 그 중 RFQ 진행 10-30건 = 거래 1-5건.
